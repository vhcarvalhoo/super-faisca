Extrair falas para gravar

Esta página gera todas as missões várias vezes e junta tudo o que o app fala, das frases mais importantes para as menos. Abra pelo python servir.py (endereço http://localhost:8765/ferramentas/extrair_falas.html) e clique no botão. O resultado vai para ferramentas/falas.json, que o gerar_vozes.py usa.
